# v60 - Ajuste visual Cuentas Corrientes y Conciliacion

Fecha de corte: 2026-07-21

## Cambio aplicado

Se reorganizo la vista de Cuentas Corrientes para mejorar lectura y uso administrativo.

## Antes

- El panel de Conciliacion estaba en una columna lateral derecha.
- Los indicadores y filtros quedaban comprimidos.
- La tabla de Cuentas Corrientes perdia ancho util.

## Ahora

- Conciliacion queda arriba de Cuentas Corrientes.
- Los indicadores de transferencias se muestran horizontalmente.
- Los filtros bancarios usan una fila amplia.
- Las acciones masivas quedan en bloque horizontal.
- El listado de comprobantes usa tarjetas en grilla.
- Cuentas Corrientes queda debajo, a ancho completo.

## Impacto

No se modifico logica financiera, estados, filtros ni validacion bancaria.

Es un ajuste de disposicion visual y cache para que el panel sea mas legible en escritorio.
