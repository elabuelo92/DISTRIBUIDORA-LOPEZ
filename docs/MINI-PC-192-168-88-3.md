# Mini PC servidor - 192.168.88.3

Fecha: 2026-06-15

Servidor asignado:

- IP fija: `192.168.88.3`
- Puerto del sistema: `8789`
- Red: LAN3 Mikrotik
- URL dashboard LAN: `http://192.168.88.3:8789/index.html#dashboard`
- URL preventa LAN: `http://192.168.88.3:8789/index.html#preventa`
- APK para celulares LAN: `android-apk\out\DL-Preventa-MINI-192-168-88-3.apk`

## 1. Copiar sistema a la mini PC

En la mini PC crear:

```powershell
C:\DistribuidoraLopez
```

Copiar y descomprimir:

```text
release\DistribuidoraLopez-Semana1-2026-06-15.zip
```

El contenido debe quedar directamente dentro de:

```text
C:\DistribuidoraLopez
```

## 2. Instalar Node.js LTS

Instalar Node.js LTS oficial para Windows.

Luego abrir PowerShell nuevo y validar:

```powershell
node --version
```

Debe mostrar una version, no "Acceso denegado".

## 3. Variables del servidor

Abrir PowerShell como administrador:

```powershell
setx /M PORT "8789"
setx /M DATA_DIR "C:\DistribuidoraLopez\data"
setx /M STATE_FILE "C:\DistribuidoraLopez\data\demo-state.json"
setx /M DL_DEFAULT_PASSWORD "CAMBIAR-CLAVE-ANTES-DE-PRODUCCION"
setx /M GOOGLE_MAPS_API_KEY "PEGAR-API-KEY"
```

Cerrar y abrir PowerShell despues de `setx`.

## 4. Diagnostico


## 12. Mikrotik

Si los celulares estan en otra red/VLAN/WiFi y no llegan a `192.168.88.3:8789`, revisar reglas del Mikrotik:

- Permitir trafico desde la red WiFi hacia `192.168.88.3` puerto TCP `8789`.
- Confirmar que LAN3 y la red WiFi tengan ruta entre si.
- Para acceso desde datos moviles/GSM no alcanza la IP local; hace falta Cloudflare Tunnel, Tailscale o URL publica HTTPS.
