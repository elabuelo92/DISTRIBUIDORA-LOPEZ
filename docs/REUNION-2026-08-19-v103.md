# Cierre de pendientes - Reunion 19/08/2026 - v103

## Alcance implementado

1. Busqueda unificada
   - Productos y clientes aceptan coincidencias parciales en cualquier posicion.
   - Los resultados visibles se ordenan alfabeticamente.
   - La carga de remitos reemplaza el selector rigido por un campo de busqueda abierto.
   - Ejemplo validado por logica: `PLUS` encuentra cualquier descripcion que contenga `PLUS`.

2. Comisiones
   - Administracion puede seleccionar vendedor, fecha desde y fecha hasta.
   - Se muestra cantidad, monto bruto, porcentaje efectivo e importe de comision por producto.
   - Se permite imprimir/guardar como PDF y exportar una planilla compatible con Excel.
   - `Registrar pago` liquida el periodo sin borrar pedidos ni historial. Los pedidos quedan marcados como liquidados y la operacion se audita.

3. Stock y cartera
   - Se ocultaron `Nuevo producto`, `Ingreso stock` y `Compra demo` del modulo Stock.
   - El alta operativa queda dentro de Proveedor -> Remito -> Producto -> Validacion administrativa.
   - Se agrego seleccion masiva de productos visibles y acciones Activar/Inactivar, con motivo, confirmacion y auditoria.

4. Proveedores
   - Se agrego la accion `Editar`.
   - La edicion conserva saldos, compras, pagos y movimientos.
   - Si cambia la razon social, se actualizan referencias en productos y movimientos de proveedor.

5. Clientes
   - El alta y edicion ya transportaban `horario_atencion` entre interfaz, API y estado.
   - Se ajusto el ejemplo visible a `8-14 / 16-22`.

6. Reparto y mapas
   - El Dashboard ya preservaba zoom cuando solo cambiaban coordenadas.
   - La hoja de ruta ahora tambien preserva zoom y encuadre mientras se actualizan sus datos.
   - `Ir al cliente` usa el puente Android para abrir Google Maps externamente.
   - Los controles de camara, galeria y PDF siguen disponibles mediante el selector nativo Android.
